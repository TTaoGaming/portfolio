Catching AI agents when they lie about being done.

Pre-release adversarial audits, a free open-source claim-checker, and a field guide of ten real, caught failure modes — plus a couple of live browser demos along the way. Everything linked below is verified live at the time of publishing.

The product

live

AgentReleaseGate

Pre-release adversarial audits for AI agents: reward-hacking, eval-gaming, and false-green results — the failures internal evals structurally miss, because the same team usually builds and grades them.

Free & open

live

agentreleasegate-oss

The published policy behind the product, free and MIT-licensed. Two ways in: claim_gate/ — one JSON claim in, ALLOW/DENY out, with an OPA engine and a zero-dependency Python fallback — and reward_hack_mirror/, an 8-rule version with a tamper-evident hash chain. No signup, no network call, no account required to run either.

The AI-Agent Failure-Mode Field Guide

Ten ways an agent lies about being done — frame-override, false-green, phantom citations, self-consistency mistaken for verification, and more — each one named, dated, and caught in a real project, with the mechanical check that catches it. Citations grep-verified against source records; see the guide's own footer for the honest limits of that verification.

The heritage story

This work comes out of an 18-month, solo AI-agent build (Jan 2025–present) that started as an attempt to build useful software with AI coding agents and turned, gradually, into a project about trusting them — after watching the same handful of failure patterns recur across model families: a "done" that wasn't tested, a "sent" that was only drafted, a self-review that agreed with itself because it shared the same blind spots as the work it was reviewing. AgentReleaseGate and the tools above are the distilled, generalized version of the checks built to catch exactly that, running against a project's own recorded record of ~1,000 real successes and failures.

None of this claims to catch every way an agent can fake progress — the field guide and the OSS gate are both explicit about their limits. The claim is narrower and, I think, more useful: these catch a few specific, common, machine-checkable lies, deterministically, every time.
