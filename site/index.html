Tommy Tai · independent builder and researcher

From human movement to systems people can interact with.

I worked as an exercise therapist before building browser experiences, spatial input systems, and tools for checking the work of AI agents. The common thread is practical feedback: observe what happens, make a useful change, and test whether it really worked.

The through-line

A hands-on path into software

01 / Movement

Exercise therapy

My earlier work was with people and physical movement. That background still shapes how I think about feedback, accessibility, and whether an interaction actually makes sense to a person using it.

02 / Interaction

Spatial and browser experiments

I started turning cameras, gestures, and ordinary browser input into playable experiences. The larger Spatial Input work aims to translate noisy sensor observations into stable events an application can use.

03 / Verification

AI systems and research

Working with AI coding agents led me to build checks for false completion claims and brittle self-review. I now publish public tools, demos, and research packets with their evidence and limits attached.
